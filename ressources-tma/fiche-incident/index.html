Fiche incident applicatif

Une fiche bien renseignée réduit le temps perdu lors de la qualification initiale.

Informations minimales

Application : nom et module.
Date/heure : première occurrence et dernière occurrence.
Utilisateur(s) impacté(s) : nombre et profils.
Impact métier : bloquant, majeur, mineur.
Étapes de reproduction : actions exactes.
Résultat attendu / obtenu : comparaison.
Environnement : production, recette, navigateur, OS, version.
Éléments techniques : message d'erreur, logs, captures, ID transaction.
Contournement : disponible ou non.
Actions déjà tentées : redémarrage, retry, cache, autre.
